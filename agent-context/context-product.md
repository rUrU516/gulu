# 产品范围与决定

## 当前明确要求（2026-10-12）
- 名称 gulu / 咕噜。
- 先保留常驻 macOS 顶部菜单栏小图标；用户后来明确添加“从图标退出应用”的要求。
- 用户拒绝上一轮“测试提醒 → 喝水窗口”的实现，要求先缩到最小骨架，并做好版本管理。
- 当前水滴图标可以打开只有“退出”的原生菜单，不创建窗口；用户确认实际退出成功并要求使用简短文字“退出”。实现见 [菜单栏最小版本](context-menubar.md)。
- 用户询问图标变化、闪烁，以及从图标弹出/吐出内容的可行性。已探查图片换帧、贴图标的小窗口、AppKit NSPopover；没有授权具体动画效果的实现，不自动扩展本轮代码。
- 用户要求重启后讨论具体提醒效果；目前进入效果讨论，尚未选定或授权某个提醒效果的实现。不根据此前讨论自动恢复提醒、计时、通知、宠物动画或记录功能。

## 保留背景
- 最初想为女朋友或两人互动做可爱的小 macOS 应用，曾设想喝水提醒和宠物感。
- 用户通过计算器学习 Rust/Tauri，然后尝试了手动提醒窗口。两项代码和当时的记录在 learning-baseline 中保留。
- 最终产品的提醒周期、宠物形象、位置等尚未确定；这些不是当前任务。
