# 产品范围与决定

## 当前明确要求（截至 2026-10-13）
- 名称 gulu / 咕噜。
- 先保留常驻 macOS 顶部菜单栏小图标；用户后来明确添加“从图标退出应用”的要求。
- 用户拒绝上一轮“测试提醒 → 喝水窗口”的实现，要求先缩到最小骨架，并做好版本管理。
- 用户确认实际退出成功并要求菜单使用简短文字“退出”。当前菜单有“试试提醒”和“退出”，实现见 [菜单栏入口](context-menubar.md)。
- 用户随后明确要求保持当前水滴形象，以状态栏图标为起点放大/跳出提醒喝水，再自动缩回；已做手动演示，用户确认“出现了且自动缩回了”。透明原生窗口只在动画期间显示，见 [动画 Context](context-animation.md)。
- 最新明确要求每 5 分钟自动播放同一动画，提示文字改成“记得喝水”，其他保持不变；保留现有菜单与 4.8 秒收回效果。不添加通知、记录或其他功能。

## 保留背景
- 最初想为女朋友或两人互动做可爱的小 macOS 应用，曾设想喝水提醒和宠物感。
- 用户通过计算器学习 Rust/Tauri，然后尝试了手动提醒窗口。两项代码和当时的记录在 learning-baseline 中保留。
- 当前提醒周期与形象已确定为每 5 分钟、原水滴形象、从菜单栏图标起点弹出；其余产品方向等待明确需求。
