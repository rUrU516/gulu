## 当前范围（截至 2026-10-13）
- 保持常驻 macOS 顶部菜单栏的水滴形象；菜单提供“试试提醒”“检查更新”和“退出”，用户此前已确认实际退出成功。
- 用户要求从图标原位置放大/跳出提醒，再自己缩回；用户已确认这个动画效果可正常出现并收回。
- 最新要求：每 5 分钟自动播放，提示文字为“记得喝水”，其余效果不变。启动后首次等待 5 分钟；仍可手动点“试试提醒”。
- 动画期间创建透明原生窗口，约 4.8 秒后收起并恢复图标，没有通知或记录。
- 名称 gulu / 咕噜，Identifier 为 com.zhuoru.gulu。
- 当前实现是 Rust + Tauri 菜单栏代码，加上 Rust 通过 objc2 调用 AppKit 原生窗口/图片/动画定时器；无需前端页面或 Vite。
- 用户要求做好版本管理：项目已初始化本地 Git，旧计算器/手动提醒代码保存在 learning-baseline。
- 用户要求打包分享给女朋友，主要面向 Apple 芯片；已生成 0.1.0 的 arm64 正式构建 DMG。本机无 Developer ID 分发证书，应用为 ad-hoc 本地签名，未 Apple 公证，首次打开可能需系统授权例外。
- 最新要求“检查更新”与 GitHub Release：0.1.1 增加菜单检查并提供新版下载页面；用户确认的公开仓库 https://github.com/rUrU516/gulu 已同步并发布 v0.1.1。pnpm release 本地构建/校验/上传/发布已实际跑通，匿名下载与应用真实检查通过；用户已确认菜单检查显示最新版提示，详见更新 Context。
- 用户接着要求向前发布一个版本以测试更新；已发布 v0.1.2，只升级版本号，功能不变。公开最新 Release、真实更新请求和匿名下载文件一致性均已验证。为避免开发 watcher 自动升级，已停止开发进程并启动独立保存的 0.1.1 正式包供用户测试；详见更新 Context。
